# Estatística descritiva
Selecione primeiro parâmetro/ponto/período com `get_series`. Só então chame `descriptive_statistics`. Use `search_technical_references` quando a interpretação metodológica ou ambiental exigir fundamento. Dados censurados não devem ser tratados como observações exatas apenas para facilitar a narrativa.
