# Tendência
Confirme presença de data, selecione a série com `get_series` e execute `mann_kendall_trend` somente no subconjunto solicitado. Consulte referências técnicas para limitações, especialmente censura, sazonalidade e tamanho amostral. Não aplique automaticamente a todos os parâmetros do banco.
